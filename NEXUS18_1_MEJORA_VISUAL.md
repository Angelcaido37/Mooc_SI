# NEXUS 18.1 · Mejora de experiencia de acceso

NEXUS 18.1 conserva la arquitectura pedagógica, evaluación, analítica, trazabilidad, privacidad y backend de NEXUS 18.

## Cambios de interfaz
- Acceso rediseñado con tarjeta institucional y jerarquía visual.
- Selector Estudiante/Docente mediante botones accesibles.
- Campos separados, etiquetas superiores y espaciado consistente.
- Los campos de estudiante y docente aparecen solo cuando corresponden.
- El aviso de privacidad se solicita al estudiante; no bloquea el acceso docente.
- Mostrar/ocultar contraseña docente.
- Diseño responsive para escritorio y móvil.
- Se retiró del login el texto técnico sobre FastAPI/SQLite/Firebase/Classroom.

## Despliegue
Esta edición está alineada con **GitHub Pages + Render**. El código de curso sigue siendo `NEXUS18` para mantener compatibilidad con las variables ya configuradas en Render.
