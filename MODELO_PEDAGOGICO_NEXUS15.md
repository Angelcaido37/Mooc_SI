# Modelo pedagógico NEXUS 15

NEXUS 15 organiza el aprendizaje como un ciclo: **activar → problematizar → explorar → construir → aplicar → demostrar → retroalimentar → mejorar → reflexionar**.

## Metodologías integradas

La plataforma contempla aprendizaje basado en problemas, aprendizaje basado en proyectos, indagación, STEAM y aprendizaje cooperativo. Las metodologías se vinculan a misiones y resultados de aprendizaje, no se usan como etiquetas decorativas.

## Gamificación

XP, niveles, insignias, narrativa, NexoCoins, tienda y retos sostienen motivación y progreso. Se distinguen los retos de participación de los **retos de dominio**. Las recompensas cosméticas no aumentan la calificación.

## Evaluación auténtica

Cada actividad evaluable debe pertenecer a una categoría y ponderación. Las seis evidencias vienen predefinidas y se revisan mediante rúbricas. El sistema permite retroalimentación y reentrega para documentar mejora.

## Medición del aprendizaje

NEXUS separa participación, desempeño y aprendizaje. El pretest/postest estima cambio; las evidencias y retos de dominio aportan evidencia de desempeño. Una asociación entre uso de actividades y mejora no se interpreta automáticamente como causalidad.

## Analítica para la acción docente

Las alertas se diseñan para identificar baja participación, inactividad, bajo desempeño y criterios de rúbrica con dificultad colectiva. Cada alerta debe acompañarse de una recomendación revisable por el docente. NEXUS no debe tomar automáticamente decisiones de aprobación, reprobación o diagnóstico.
